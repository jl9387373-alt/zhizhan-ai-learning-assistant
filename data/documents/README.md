# 知识库文档存放指南

您可以将任何想要让 AI 学习的文件放在此目录下。系统会自动扫描并将其加入知识库。

## 支持的文件格式
- **文档**: `.pdf`, `.md`, `.txt`
- **代码**: `.py`, `.js`, `.ts`, `.java`, `.c`, `.cpp`, `.html`, `.css`
- **结构化数据**: `.json` (需包含 `text` 字段)

## 如何导入网页？
在 `data/` 目录下创建一个名为 `urls.txt` 的文件，每行填入一个完整的 URL（如 `https://example.com`），系统在下次启动或重建索引时会自动抓取这些网页内容。

## 提示
- 文件名建议包含关键词（如 `Python并发编程.pdf`），有助于系统自动识别主题。
- 如果添加了新文件，系统通常会自动检测并重建索引。如果没有自动更新，可以尝试重启应用。
