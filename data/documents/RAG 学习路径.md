# RAG 学习路径：从原理到可评测的检索系统

RAG 的学习难点不在概念，而在"怎么判断改得对不对"。这条路径按五个阶段展开，每个阶段都给一个能立刻动手的练习。

## 1. 一句话理解 RAG

检索增强生成（RAG）：先从知识库检索与问题相关的片段，再让模型基于这些片段作答，从而提升准确性、可解释性，并让答案可以追溯到具体资料。

## 2. 学习路径：先学什么，再学什么

**第一阶段 · 跑通最小链路**
加载文档 → 切分 → 向量化 → 检索 → 生成。目标：能让一篇文档被正确检索并用于回答。
关键概念：切分粒度、向量相似度、上下文拼接。

**第二阶段 · 提升检索质量**
混合检索（向量 + 关键词）、重排（rerank）、相似度阈值、同义扩展。
目标：同一个问题，前三条召回是否都相关。

**第三阶段 · 提升生成质量**
提示词约束（只基于资料作答）、引用标注、无资料时的降级策略。
目标：资料不足时，系统敢说"没有找到"，而不是硬编。

**第四阶段 · 建立评测**
构建测试集、定义指标（召回率、答案正确率、无资料识别率）、Bad Case 归类。
目标：每次改动前后有可比数字。

**第五阶段 · 工程化**
增量更新、缓存、成本与延迟、文档治理（同主题重复）。
目标：能算出一次问答的成本，并说清瓶颈在哪。

## 3. 每个阶段练什么

1. 阶段一练习：把 3 篇文档切块后检索 10 个问题，人工检查前 3 条是否相关
2. 阶段二练习：同一问题分别用"纯向量"和"混合检索"，记录命中差异
3. 阶段三练习：故意问一个知识库里没有的主题，观察系统是否会承认无资料
4. 阶段四练习：造 20 条测试用例，统计答对率与失败类型分布
5. 阶段五练习：统计一次完整问答的 token 消耗与响应时间

## 4. 常见坑

- **资料类型与问题类型不匹配**：库里存的是"是什么"和"我们怎么做"，用户问的是"怎么学"，检索再准也答不出来
- **关键词命中当成主题命中**：把"解释""是什么"这类问句虚词当作主题词，任何写着"解释 XX"的文档都会被判为相关
- **只调阈值不做评测**：阈值调高会漏召回，调低会引入噪声，没有测试集就无法取舍
- **没有降级策略**：库外主题强行用相近片段作答，比直接说"没有资料"伤害更大
- **同主题重复文档**：同一内容存在 PDF 与 MD 两份，容易召回重复片段，答案出现重复表述

## 5. 怎么判断自己学会了

能回答下面四个问题，就算入门：

1. 召回不准时，先看资料还是先看阈值？
2. 什么情况下系统应该承认"知识库没有这个主题"？
3. 改动之后，用什么证明它变好了？
4. 用户问的主题不在库里，正确的产品行为是什么？
