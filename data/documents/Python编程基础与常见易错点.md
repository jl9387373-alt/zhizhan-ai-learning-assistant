# Python 编程基础与常见易错点

Python 是当前教学、数据分析、人工智能和工程开发中常用的编程语言之一。本文档围绕 Python 基础语法、核心数据结构和常见易错点进行整理。

## 1. Python 的基本特点
- 语法简洁，适合初学者入门
- 支持解释执行，开发效率较高
- 拥有丰富的第三方库生态
- 既可用于脚本开发，也可用于后端、数据分析、人工智能等场景

## 2. 基本数据类型
Python 中常见的内置数据类型包括：
- `int`：整数
- `float`：浮点数
- `str`：字符串
- `bool`：布尔值
- `list`：列表
- `tuple`：元组
- `dict`：字典
- `set`：集合

理解这些类型的区别，是后续学习函数、面向对象和算法的基础。

## 3. 列表、元组、字典、集合的区别

### 3.1 列表 list
- 有序
- 可变
- 支持增删改查

### 3.2 元组 tuple
- 有序
- 不可变
- 适合存放不希望被修改的数据

### 3.3 字典 dict
- 键值对结构
- 通过键快速查找值
- 键必须是可哈希对象

### 3.4 集合 set
- 元素无序且不重复
- 常用于去重与集合运算

## 4. 条件语句与循环

### 4.1 条件语句
Python 使用 `if`、`elif`、`else` 控制分支逻辑。

### 4.2 循环
- `for`：适合遍历序列
- `while`：适合条件控制循环

在编写循环时，应特别注意循环终止条件，避免死循环。

## 5. 函数
函数用于封装可复用逻辑，提高代码的模块化程度。

### 5.1 函数定义

```python
def add(a, b):
    return a + b
```

### 5.2 常见参数类型
- 位置参数
- 默认参数
- 可变参数 `*args`
- 关键字参数 `**kwargs`

### 5.3 返回值
Python 函数可以返回单个值，也可以返回多个值，本质上多个值会被封装成元组。

## 6. 面向对象基础
Python 支持面向对象编程，核心概念包括：
- 类
- 对象
- 封装
- 继承
- 多态

示例：

```python
class Student:
    def __init__(self, name):
        self.name = name

    def introduce(self):
        return f"我是{self.name}"
```

## 7. 常见易错点

### 7.1 可变对象作为默认参数
下面这种写法容易产生意外结果：

```python
def append_item(item, data=[]):
    data.append(item)
    return data
```

原因在于默认参数只在函数定义时初始化一次，后续调用会复用同一个列表。更稳妥的写法是使用 `None` 作为默认值。

### 7.2 浅拷贝与深拷贝混淆
- 浅拷贝只复制最外层对象
- 深拷贝会递归复制内部对象

当处理嵌套列表、字典时，若不了解这一点，容易出现“改了副本却影响原对象”的问题。

### 7.3 `is` 与 `==` 混淆
- `==` 比较值是否相等
- `is` 比较对象是否为同一实例

### 7.4 列表推导式可读性过差
列表推导式虽然简洁，但嵌套过深会降低可读性。复杂逻辑应优先拆分为普通循环或函数。

### 7.5 异常处理过于宽泛
不建议直接使用裸 `except:`，否则容易掩盖真实错误。更合理的做法是捕获明确的异常类型。

## 8. 常见教学考点

- 深拷贝与浅拷贝

## 9. 学习建议
Python 学习不应停留在语法记忆层面，而应注重“语法理解 + 编程实践 + 错误调试”。对于初学者来说，能读懂报错信息、定位常见 bug，与会写语法同样重要。
