# 计划输入引导迭代记录

## 发现

5 人独立试用“建计划 → 答疑 → 记录进度 → 返回后找到下一步”，均最终完成；其中 2 人在制定计划时不确定该用什么格式输入需求。样本是熟人便利抽样，没有逐人原话、录屏或耗时记录。

## 改动

- 从仪表盘、学习计划页、新对话欢迎区进入创建计划时，显示简短引导。
- 输入框给出 RAG 学习计划示例，提示区给出完整示例。
- “学习主题、目标、周期、每天时间”可点击插入输入框；信息由用户自行填写或修改，不设为必填。
- 示例只填入草稿，不自动发送。发送后收起引导。

改动文件：`static/index.html`、`static/app.js`、`static/styles.css`。没有修改后端计划生成逻辑。

## 验证与边界

原项目页面已显示引导区和示例；截图见下方。JavaScript 语法与关键函数交互检查通过。项目负责人邀请首次试用中卡在输入格式的同 2 人复测，反馈两人更容易开始输入。这是定性反馈，未记录逐人操作过程，不能据此宣称完成率或效率提升。
