# 知栈 · AI 学习助手

知栈是一个可在本地运行的学习工作台：通过自然语言制定学习计划、答疑、记录进度和安排复习。项目包含 Flask 后端、Agent 协调与服务、RAG 知识检索、前端页面及自动化测试。

## 版本说明

首次上传的是**计划输入引导改版前的重建快照**：主体代码取自本地项目在 2026-11-27 的状态，`static/index.html`、`static/app.js`、`static/styles.css` 使用覆盖前备份。它用于展示这次迭代的前后差异，不代表项目最初版本的完整提交历史。

第二次提交在同一路径更新这三个前端文件，增加计划输入示例和“学习主题、目标、周期、每天时间”四项快捷提示。改动详情见[迭代记录](docs/计划输入引导迭代记录.md)。

## 本地运行

1. 安装 Python 3.9+，执行 `pip install -r requirements.txt`。
2. 将 `config.example.json` 复制为 `config.json`，按自己的模型服务配置 API Key。不要提交 `config.json`。
3. 执行 `python app.py`，浏览器打开 `http://127.0.0.1:5000/`。

仓库只附少量示例知识库 Markdown 文档。完整的本地知识库、向量索引、用户账号、对话和计划数据均未上传；因此从仓库新建环境时，需要自行补充知识库文档并重建索引。

## 主要目录

- `agents/`、`core/`、`memory/`、`nlp/`：Agent、路由、上下文与计划约束。
- `rag/`：文档加载、检索和回答。
- `static/`：前端页面和样式。
- `storage/`：持久化逻辑的 Python 源码，不含用户数据。
- `tests/`、`scripts/`、`tools/`：测试与开发工具。
- `data/documents/`：少量示例知识库文档。

## 产品迭代背景

一次 5 人任务试用中，5 人最终都独立完成建计划、答疑、记录进度和返回找下一步；其中 2 人在建计划时不确定如何描述输入。随后针对这 2 人做计划输入引导改版：在创建计划入口提供一句可编辑示例，并允许点选四项信息提示。项目负责人邀请原先卡住的同 2 人复测，反馈他们更容易输入学习需求。这是定性观察，尚无逐人操作记录，不能写成量化提升或推广到其他用户。

本仓库用于展示个人项目和迭代过程。示例知识库文档仅作演示；其余大型 PDF 和本地数据未随仓库提供。
